# QHI-automation v2.1
数码印刷智能拼版与生产管理系统

基于 E:\e.txt 指令，对照国内数码印刷行业标杆（世纪开元、快印客、灵燕印刷 ERP、畅捷通快印 ERP）的最佳实践，以及国家新闻出版署「十四五」印刷业高质量发展指标体系，对当前项目进行标准化、易用性、便捷性、可扩展性四维优化。

## 核心功能

### 1. 智能拼版系统
- 集成 KPSM_v3.0 XML模板引擎（Quite Hot Imposing 5）
- AI算法拼版（贪心+模拟退火）
- 自动模式选择（小批量AI，大批量QHI模板）
- 支持5种拼版场景：环衬拼版、替换后环衬、康轩删面底、内页提取合拼、康轩多本连拼

### 2. 印特ERP完整接管
- 建单：自动工单号生成（GD+YYMMDD+5位序号）
- 转单：9种流程状态流转（排队→审单→前期→机房→后道→外发→完工→寄快递→未付）
- 审单：审核通过/驳回/要求修改
- 统计：日统计、客户排名、流程分布、月度营收
- 查询：多条件组合查询、精确查询、最近工单

### 3. 数字印刷机对接
- HP Indigo 12000/7900：REST API + 热文件夹
- Oce VarioPrint 6000：PRISMAsync SMB热文件夹 + SNMP
- Konica Minolta bizhub 287：RAW 9100直打 + LPR
- XP-80热敏小票：USB串口

### 4. 生产管理系统
- 工单生命周期管理
- 订单审批工作流
- 热文件夹调度器
- 设备机队监控
- 耗材管理
- 报表统计

## 技术架构

- 前端：PyQt5桌面应用 + Web移动端
- 后端：Python 3.7+
- 数据库：SQLite（本地） + SQL Server（印特ERP）
- 通信：WMI远程SQL查询、REST API、SNMP、RAW/LPR打印协议

## 快速启动

```bash
cd E:\qhi_processor
python main.py
```
